# Документация проекта

## Проект

**momentum** — сервис одноразового обмена зашифрованными сообщениями и файлами (текст ≤ 10 000 символов, файл ≤ 5 МБ). Шифрование и расшифровка только на клиенте, сервер хранит один шифротекст не дольше 7 дней (по умолчанию 24 часа, по умолчанию удаление после первого чтения). Ключи через сервер не проходят. Идея и требования: [idea.md](./idea.md).

## Назначение

Зафиксировать актуальное устройство, дизайн и функциональные единицы проекта.
