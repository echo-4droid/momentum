# Основное

Стек и криптомодуль v1 зафиксированы; MVP реализован (server/ + client/), E2E пройден.

## Назначение проекта

Обмен зашифрованными сообщениями/файлами по одноразовым ссылкам с E2EE: сервер — «глупое» хранилище шифротекста с TTL, вся криптография на клиенте.

## Стек

- Клиент: React Native → web (Expo SDK, TypeScript), WebCrypto + Argon2id (WASM, hash-wasm). Статический бандл.
- Сервер: C# / ASP.NET Core Minimal API, self-contained publish, один процесс, статика клиента из того же процесса.
- Требования к инфраструктуре: 1 vCPU / 512 МБ RAM / 5–10 ГБ диск, Linux.

## Криптомодуль v1

- Фраза: генерируется клиентом из EFF large (7776), число слов выбирает создатель — 6–10 (по умолчанию 8 ≈ 103.4 бита), разделитель «-»; CSPRNG с reject-семплированием; получатель вводит слова на странице чтения; ввод нормализуется (trim → NFKC → UTF-8) перед KDF.
- KDF: Argon2id m = 65536 КиБ, t = 3, p = 1, salt 16 байт, ключ 32 байта; WASM, однопоточно; ориентир ≤ 2–3 с на средних мобильных.
- Шифр: AES-256-GCM (WebCrypto), nonce 12 байт, тег 16 байт в конце; AAD = заголовок конверта.
- Конверт: magic `MOMO` (4 б) | version (1 б) | alg_id (1 б) | m_kib (u32 LE) | t | p | salt_len | nonce_len | salt | nonce | ciphertext‖tag. Заголовок до шифротекста — 42 байта; побайтовая таблица в [idea.md](../idea.md).
- Режимы: alg_id 0x02 — «ключ в ссылке» (по умолчанию): ключ 32 байта CSPRNG в URL-фрагменте (фрагмент остаётся в браузере), в заголовке m/t/p = 0, salt — случайный неиспользуемый; alg_id 0x01 — фраза + Argon2id. Layout одинаков, блобы режимов неразличимы по форме; AAD покрывает alg_id — подмена режима обнаруживается при расшифровке.
- Версии: version маппится на зарегистрированный набор параметров с валидацией; новые дефолты выходят новой версией (+1, номер используется один раз); reader поддерживает все старые версии, writer пишет последнюю; сервер, API и формат ссылки работают с любой версией одинаково.

## Компоненты и границы

- Веб-клиент (SPA): создание секрета, генерация и ввод парольной фразы, шифрование/расшифровка, чтение по ссылке.
- Сервер API: приём/выдача непрозрачных шифроблобов, лимит 8 МБ, TTL 1 ч–7 дней (по умолчанию 24 ч), one-time чтение с транзакционным удалением (блоб получает победитель удаления), квота суммарного размера блобов (2 ГиБ + резерв диска, сверх — 507; счётчик сериализован в процессе, при старте — миграция и пересчёт, чистка вычитает длины удаляемых записей), проверка доступности без выдачи блоба (`/{id}/status` — для мгновенного статуса на странице чтения). POST читает тело одной копией (точный массив по Content-Length). Ответы GET — `Cache-Control: no-store` (шифротекст живёт только в памяти браузера). Потолок параллельных соединений Kestrel — 16: с одной копией блоба на POST худший случай ≈ 2 × 8 МиБ × 16 ≈ 256 МиБ на профиле 512 МиБ.
- Фоновый сервис чистки: удаление просроченного; ежечасно Checkpoint журнала БД, ежедневно Rebuild (возврат страниц удалённых записей; резервные копии Rebuild удаляются — вне квоты).
- Хранилище: LiteDB (полностью managed — работает на любом glibc, который тянет .NET); шифрование файла паролем `Momentum:DatabasePassword` (пароль применяется при создании БД, передаётся типизированным свойством подключения и переживает Rebuild).

## Данные и интеграции

Единственная сущность: `id (16 байт, CSPRNG) | blob ≤ 8 МБ | expires_at | one_time | created_at`.
Все запросы клиента идут на собственный сервер (ассеты self-hosted); внешние интеграции отсутствуют.

## Развёртывание и эксплуатация

- Сборка клиента вшита в сборку сервера (MSBuild-таргет `BuildClient` в `Momentum.csproj`): сборка сервера сверяет SHA-256 `package-lock.json` со штампом последней установки в `node_modules` — при несовпадении выполняется `npm ci` → `expo export --platform web` → копирование `client/dist` в `wwwroot`.
- Разработка и публикация: команды — в [README.md](../../README.md), пошаговое ручное развёртывание — в [DEPLOYMENT.md](../../DEPLOYMENT.md).

Пакет = один бинарник ~97 МиБ + `wwwroot/`: на VPS требуются только nginx и TLS-сертификат. TLS-терминация на nginx (пример: [deploy/nginx.conf.example](../../deploy/nginx.conf.example)), Kestrel слушает только на localhost. Access-логи выключены, рейт-лимиты в памяти. Криптосхема и модель безопасности: [idea.md](../idea.md).
