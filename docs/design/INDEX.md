# Основное

Дизайн реализован и соответствует коду клиента (`client/src/ui.tsx`, `CreateScreen.tsx`, `ReadScreen.tsx`). Этот документ — источник факта.

## Принципы

- Один акцентный цвет (синий) для всех действий; красный — только ошибки и PDF-бейдж.
- Секретные строки (ссылка, фраза) — моноширинно, рядом «Копировать».
- Ошибки — человекочитаемые, одним текстом («Секрет недоступен…», «Ссылка неполная»).
- One-time: предупреждение до открытия и после чтения.
- Один экран = одна задача, контент одной колонкой по центру; экран выбирается по пути (`/s/<id>` → чтение, `/` → создание, прочее — заглушка 404).

## Токены (`src/ui.tsx`)

Тексты интерфейса (включая a11y-лейблы, подписи опций и единицы размеров) собраны в `src/l10n.ts` — правки локализации делаются только там.

### Геометрия

- Контент: одна колонка, max-width 560, паддинги 16 / 32 / 48 (верх/бок/низ).
- Карточка: радиус 12, рамка 1 `border`.
- Кнопка primary: радиус 10, вертикальный паддинг 15; disabled — opacity 0.6.
- Поле ввода: радиус 10, паддинг 14/12.
- Панель модалки: радиус 14, затемнение `rgba(23,23,28,.45)`, max-width 440, max-height 90% экрана: содержимое скроллится (панель выросла с сегментом числа слов), футер с «Отмена»/«Сохранить» закреплён и виден всегда.

## Атомы

- **Primary button** — единственный вид кнопки-действия; busy-состояние выражается текстом («Шифруем…», «Открываем…») и disabled.
- **CopyLink** — текстовая ссылка «Копировать» рядом со значением; после клика «Скопировано» 1,5 с.
- **Copy field** — значение (mono, одна строка) + вертикальный разделитель + CopyLink в одной рамке.
- **FileBadge** — квадрат 40×40 с расширением файла (до 4 символов, верхний регистр); PDF — красный.
- **Segmented** — сегментный переключатель: рамка-контейнер, активный сегмент залит синим (TTL, режим передачи).
- **formatBytes** — «1,2 МБ» / «512 КБ» / «64 Б» (десятичная запятая).

## Экраны

### Создание (`CreateScreen.tsx`)

Логотип → «Создать секрет» → карточка (textarea от 120 px + строка файла: бейдж, имя, размер, «✕»; либо «Прикрепить файл до 5 МБ») → строка сводки «TTL • Одно чтение • Режим — Изменить» → кнопка. Ошибки — под кнопкой.

Модалка настроек: сегменты срока, чекбокс «Удалить после первого открытия» (20×20, галочка на синем), сегменты «Скрыть содержимое через» (выкл/15 с/30 с/60 с) и «Удалить со страницы через» (выкл/5 мин/10 мин/30 мин) с пояснением, что таймеры запускаются у получателя; в режиме фразы — сгенерированная фраза (mono, только чтение), сегменты «Слов во фразе» (6–10, смена значения порождает новую фразу), ссылка «Новая фраза» и подпись с энтропией («≈ N бит»); при нехватке высоты экрана содержимое панели скроллится, футер закреплён.

Результат «Ссылка готова»: copy field ссылки (без `https://`), в режиме фразы — второе поле с фразой и подсказкой «передавайте отдельно»; в режиме ключа — подсказка о том, что секрет прочитает любой, у кого окажется ссылка; «Создать ещё» сбрасывает форму и генерирует новую фразу.

### Чтение (`ReadScreen.tsx`)

«Открыть секрет» → предупреждение «Одноразовый секрет удалится при открытии» → кнопка «Открыть». Сразу при загрузке страницы выполняется запрос статуса: для прочитанного или истёкшего секрета вместо поля и кнопки выводится «Секрет недоступен…». Ключ в hash ссылки (`#…`): поле фразы скрыто, кнопка доступна сразу. Повреждённый фрагмент — сообщение «Ссылка неполная», запрос к серверу выполняется только по кнопке.

После расшифровки: заголовок «Секрет», текст с CopyLink, карточка файла с «Скачать» (Blob URL, имя файла), подсказка с отсчётом скрытия и сроком удаления со страницы. Неверная фраза — повторная попытка по локальной копии блоба. Полученный блоб хранится в памяти до конца открытия.

Таймеры создателя (поле `view` внутри конверта):

- **Скрытие (обратимое)** — содержимое и подсказка заменяются занавесом (высота 200, радиус 12): canvas-зерно из пяти слоёв точек — у каждого слоя свой размер точки (1–2,8 px) и скорость (5–23 px/с); направление дрейфа общее (20°) с отклонением слоёв до ±5°, отрисовка через `requestAnimationFrame`, DPR до 2×. По центру — кнопка «Показать содержимое» (primary). Переходы плавные: появление занавеса 350 мс, растворение 250 мс, возврат контента 300 мс.
- **Удаление со страницы (до конца открытия)** — дедлайн фиксируется в момент расшифровки и остаётся неизменным при повторных показах; по истечении состояние payload сбрасывается (текст, файл и блоб уходят из DOM и React-состояния), вместо занавеса плавно появляется карточка «Время показа истекло»: содержимое убрано с этой страницы; пока сервер хранит секрет, обновление страницы откроет его заново с полными таймерами.

Зерно рисуется на голом `<canvas>` внутри контейнера по `nativeID` (RN-Animated двигает только целые представления); все запросы идут на собственный сервер.
