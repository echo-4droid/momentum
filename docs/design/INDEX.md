# Дизайн

## Статус

Реализован и соответствует коду клиента (`client/src/ui.tsx`, `CreateScreen.tsx`, `ReadScreen.tsx`). Макеты не сохранились; этот документ — источник факта.

## Принципы

- Один акцентный цвет (синий) для всех действий; красный — только ошибки и PDF-бейдж.
- Секретные строки (ссылка, фраза) — моноширинно, рядом «Копировать».
- Ошибки — человекочитаемые, без технических деталей; причина невозможности расшифровки не раскрывается.
- One-time: предупреждение до открытия и после чтения.
- Один экран = одна задача, контент одной колонкой по центру; навигации нет — экран выбирается по пути (`/s/<id>` → чтение, иначе создание, прочее — заглушка 404).

## Атомы

- **Primary button** — единственный вид кнопки-действия; busy-состояние выражается текстом («Шифруем…», «Открываем…») и disabled.
- **CopyLink** — текстовая ссылка «Копировать» рядом со значением; после клика «Скопировано» 1,5 с; без fallback (нет clipboard — ручное копирование).
- **Copy field** — значение (mono, одна строка) + вертикальный разделитель + CopyLink в одной рамке.
- **FileBadge** — квадрат 40×40 с расширением файла (до 4 символов, верхний регистр); PDF — красный.
- **Segmented** — сегментный переключатель: рамка-контейнер, активный сегмент залит синим (TTL, режим передачи).
- **formatBytes** — «1,2 МБ» / «512 КБ» / «64 Б» (десятичная запятая).

## Экраны

### Создание (`CreateScreen.tsx`)

Логотип → «Создать секрет» → карточка (textarea от 120 px + строка файла: бейдж, имя, размер, «✕»; либо «Прикрепить файл до 5 МБ») → строка сводки «TTL • Одно чтение • Режим — Изменить» → кнопка. Ошибки — под кнопкой.

Модалка настроек: сегменты срока, чекбокс «Удалить после первого открытия» (20×20, галочка на синем), сегменты «Скрыть содержимое через» (выкл/15 с/30 с/60 с) и «Удалить со страницы через» (выкл/5 мин/10 мин/30 мин) с пояснением, что таймеры запускаются у получателя; в режиме фразы — поле (mono, без автокапитализации) + «Новая фраза»; пустая фраза блокирует «Сохранить».

Результат «Ссылка готова»: copy field ссылки (без `https://`), в режиме фразы — второе поле с фразой и подсказкой «передавайте отдельно»; в режиме ключа — подсказка «вся секретность — в ссылке»; «Создать ещё» сбрасывает форму и генерирует новую фразу.

### Чтение (`ReadScreen.tsx`)

«Открыть секрет» → предупреждение «Одноразовый секрет удалится при открытии» → кнопка «Открыть». Сразу при загрузке страницы выполняется запрос статуса: если секрет уже прочитан или истёк — вместо поля и кнопки выводится «Секрет недоступен…». Ключ в hash ссылки (`#…`): поле фразы скрыто, кнопка сразу; битый/отсутствующий фрагмент — сообщение «Ссылка неполная» и **GET не выполняется** (one-time не сжигается; статус при этом не запрашивается).

После расшифровки: заголовок «Секрет», текст с CopyLink, карточка файла с «Скачать» (Blob URL, имя файла), подсказка с отсчётом скрытия и сроком необратимого удаления (см. «Таймеры создателя»). Ошибка чтения/расшифровки — один текст без причины; 404 — «уже прочитан или истёк».

Таймеры создателя (поле `view` внутри конверта):

- **Скрытие (обратимое)** — содержимое и подсказка заменяются занавесом (высота 200, радиус 12): canvas-зерно из пяти слоёв точек — у каждого слоя свой размер точки (1–2,8 px) и скорость (5–23 px/с); направление дрейфа общее (20°) с отклонением слоёв не более ±5°, отрисовка через `requestAnimationFrame`, DPR до 2×. По центру — кнопка «Показать содержимое» (primary). Переходы плавные: появление занавеса 350 мс, растворение 250 мс, возврат контента 300 мс.
- **Удаление (необратимое)** — дедлайн фиксируется в момент расшифровки и не сдвигается повторными показами; по истечении состояние payload сбрасывается (текст и файл уходят из DOM и React-состояния), вместо занавеса плавно появляется карточка «Содержимое удалено со страницы» с советом обновить страницу, если секрет ещё хранится на сервере.

Зерно рисуется на голом `<canvas>` внутри контейнера по `nativeID` (RN-Animated не умеет двигать отдельные точки); внешних запросов нет.
