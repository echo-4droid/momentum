# momentum

Сервис одноразового обмена зашифрованными сообщениями и файлами: текст ≤ 10 000 символов, файл ≤ 5 МБ. Шифрование и расшифровка — только на клиенте; сервер хранит один непрозрачный шифроблоб не дольше 7 дней (по умолчанию 24 часа) и по умолчанию уничтожает его после первого чтения. Ключи и фразы через сервер не проходят ни в каком виде.

## Как это работает

1. Отправитель пишет текст и/или прикладывает файл, клиент генерирует ключ и шифрует всё локально (AES-256-GCM, ключ из фразы через Argon2id — либо 32-байтный ключ в URL-фрагменте, браузер его серверу не отправляет).
2. На сервер уходит только шифроблоб; отправитель передаёт получателю ссылку и фразу любыми каналами по своему выбору.
3. Получатель открывает ссылку, вводит фразу (или не вводит — в режиме «ключ в ссылке»), расшифровка на клиенте. One-time секрет сгорает при первом чтении, просроченный удаляет фоновая чистка.

Криптомодуль и модель безопасности: [docs/idea.md](docs/idea.md).

## Стек

- **Клиент** — React Native → web (Expo, TypeScript), WebCrypto + Argon2id (hash-wasm). Статический бандл, внешних запросов не делает.
- **Сервер** — C# / ASP.NET Core Minimal API, LiteDB (managed, без нативных библиотек). Один self-contained бинарник, статика клиента вшивается в сборку.
- **Инфраструктура** — Linux, 1 vCPU / 512 МБ RAM, nginx с TLS; Kestrel слушает только localhost.

## Запуск

Разработка (клиент и сервер одной кнопкой, `127.0.0.1:8080`):

```
dotnet run --project server/Momentum.csproj
```

Тесты:

```
cd client && npm test      # криптомодуль: конверт, оба режима, подмены, лимиты
cd server && dotnet test   # API: create→get→404, лимиты, рейт-лимит
```

Публикация self-contained (результат в `server/publish/` — бинарник + `wwwroot/`, SDK и БД на VPS не нужны):

```
cd server && dotnet publish Momentum.csproj /p:PublishProfile=linux-x64
```

Развёртывание (systemd, nginx, TLS, обновление): [DEPLOY.md](DEPLOY.md), пример конфига nginx: [deploy/nginx.conf.example](deploy/nginx.conf.example).
