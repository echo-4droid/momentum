# Основное

momentum — сервис одноразового обмена зашифрованными сообщениями и файлами: текст ≤ 10 000 символов, файл ≤ 5 МБ. Шифрование и расшифровка выполняются на клиенте; сервер хранит один непрозрачный шифроблоб 24 часа и уничтожает его после первого чтения. Ключи и фразы существуют только на устройствах отправителя и получателя.

## Как это работает

1. Отправитель пишет текст, при желании прикладывает файл и создаёт секрет: клиент шифрует содержимое локально (AES-256-GCM), 32-байтный ключ помещается в URL-фрагмент ссылки — часть адреса после `#` остаётся в браузере.
2. На сервер уходит только шифроблоб. Отправитель передаёт получателю ссылку любым каналом.
3. Получатель открывает ссылку: клиент скачивает блоб и расшифровывает секрет. Секрет сгорает при первом чтении — повторное открытие показывает «уже прочитан».

Криптомодуль и модель безопасности: [docs/idea.md](docs/idea.md).

## Возможности

- Режим «фраза отдельно»: клиент генерирует фразу из 6–10 слов EFF (по умолчанию 8, ≈ 103 бита), получатель вводит её на странице чтения.
- Срок жизни секрета от 1 часа до 7 дней (по умолчанию 24 часа).
- Переключатель «сжечь после прочтения» (включён по умолчанию).
- Таймеры показа у получателя: скрытие содержимого (15/30/60 с) и удаление со страницы (5/10/30 мин); настройки едут внутри шифроблоба.

## Стек

- **Клиент** — React Native → web (Expo, TypeScript), WebCrypto + Argon2id (hash-wasm). Статический бандл, все запросы идут на собственный сервер.
- **Сервер** — C# / ASP.NET Core Minimal API, LiteDB (managed). Один self-contained бинарник, статика клиента вшивается в сборку.
