# momentum

Сервис одноразового обмена зашифрованными сообщениями и файлами: текст ≤ 10 000 символов, файл ≤ 5 МБ. Шифрование и расшифровка — только на клиенте; сервер хранит один непрозрачный шифроблоб не дольше 7 дней (по умолчанию 24 часа) и по умолчанию уничтожает его после первого чтения. Ключи и фразы через сервер не проходят ни в каком виде.

## Как это работает

1. Отправитель пишет текст и/или прикладывает файл, клиент шифрует всё локально (AES-256-GCM). По умолчанию 32-байтный ключ генерируется на клиенте и помещается в URL-фрагмент ссылки: часть адреса после `#` браузеры не отправляют на сервер. Второй режим — фраза.
2. В режиме фразы клиент сам генерирует фразу из 6–10 слов EFF (по умолчанию 8, ≈ 103 бита); ввести свою фразу нельзя — слабые пользовательские фразы исключены. Фразу вводит получатель на странице чтения.
3. На сервер уходит только шифроблоб; отправитель передаёт получателю ссылку (и фразу — если выбран режим фразы) любыми каналами по своему выбору.
4. Получатель открывает ссылку, расшифровка идёт на клиенте. One-time секрет сгорает при первом чтении, просроченный удаляет фоновая чистка.

Режим по умолчанию — «ключ в ссылке»: секрет прочитает любой, у кого окажется ссылка, включая мессенджер, облачную синхронизацию истории и буфер обмена. One-time сгорание в этом случае сообщает о чтении (повторное открытие даст «уже прочитан»), но не предотвращает его. Криптомодуль и модель безопасности: [docs/idea.md](docs/idea.md).

## Стек

- **Клиент** — React Native → web (Expo, TypeScript), WebCrypto + Argon2id (hash-wasm). Статический бандл, внешних запросов не делает.
- **Сервер** — C# / ASP.NET Core Minimal API, LiteDB (managed, без нативных библиотек). Один self-contained бинарник, статика клиента вшивается в сборку.
- **Инфраструктура** — Linux, 1 vCPU / 512 МБ RAM, nginx с TLS; Kestrel слушает только localhost.

## Запуск

Разработка (клиент и сервер одной кнопкой, `127.0.0.1:8080`):

```
dotnet run --project server/Momentum.csproj
```

Тесты:

```
cd client && npm test      # криптомодуль: конверт, оба режима, подмены, лимиты
cd server && dotnet test   # API: create→get→404, лимиты, рейт-лимит
```

Публикация self-contained (результат в `server/publish/` — бинарник + `wwwroot/`, SDK и БД на VPS не нужны):

```
cd server && dotnet publish Momentum.csproj /p:PublishProfile=linux-x64
```

Для сборки нужен SDK 10.0.113+ из диапазона 10.0.1xx (`global.json`, rollForward: patch); с более старым или другим диапазоном сборка завершится ошибкой. Причина: патчи рантайма и ASP.NET Core (в т.ч. Kestrel) попадают в self-contained бинарник только при пересборке — после каждого Patch Tuesday пересобирайте и перевыкладывайте пакет.

Развёртывание (systemd, nginx, TLS, обновление): [DEPLOY.md](DEPLOY.md), пример конфига nginx: [deploy/nginx.conf.example](deploy/nginx.conf.example).

## Рекомендации по развёртыванию

- **Отдельный поддомен** (например, `momentum.example.com`) вместо префикса на общем домене. Приложение доверяет отданному сервером JavaScript: любая XSS на соседнем сайте того же origin сможет читать фрагмент ссылки с ключом и подменять статику. Поддомен изолирует origin.
- **HSTS с `includeSubDomains`; `preload` — только при готовности всего домена.** Заголовок уже в конфиге nginx. `preload` (включение в список hstspreload.org) распространяет HTTPS-требование на все поддомены домена — включайте, только если весь домен работает по HTTPS и вы контролируете все его поддомены. До применения HSTS первый визит по http подменяем активным MITM.
- **`data/` вне бэкапов провайдера.** Файл БД хранит шифротекст вместе с ID из ссылок и временем жизни; удалённые записи остаются на страницах файла до Rebuild. Исключите каталог из снапшотов или зашифруйте БД паролем (`Momentum__DatabasePassword`, см. DEPLOY.md).
- **Принятые риски** (полный список и обоснования — модель безопасности в [docs/idea.md](docs/idea.md)): исчерпание квоты хранилища одним анонимным клиентом (DoS доступности), рейт-лимит по IP бьёт по CGNAT-пользователям, `/status` раскрывает обладателю ссылки факт и время доступности секрета, лаг патчей рантайма до пересборки.
